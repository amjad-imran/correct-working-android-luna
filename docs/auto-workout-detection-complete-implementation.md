## 1. What "Auto Detection" Means

The Luna Band ring detects physical activity **automatically on-device** using its accelerometer and heart-rate sensor — no user initiation required. When the ring detects a sustained activity (walking, running, or other movement), it records:

- Activity type (walking = SDK type 1, running = SDK type 2)
- Duration in seconds
- Calories burned
- Step count
- Activity intensity level
- Heart rate data during the activity
- Start timestamp (Unix epoch, **seconds** on device)

This data is stored on the ring and transferred to the Android app over BLE when the ring connects and a sync is triggered. The app stores it locally and prompts the user to **Add**, **Identify** (change type), or **Dismiss** each detected workout.

**Important filter (legacy path only):** Only workouts with `calories > 15` are stored via the legacy `AutoSportDataCallBack`. The newer `onRingAutoActiveSportData` path stores all workouts without filtering.

## 2. Core Data Bean — `OreoAutoSportData`

**File:** `commons/src/main/java/com/noisefit_commans/data/model/OreoDbTable.kt`

This is the **single source of truth** for an auto-detected workout. It is a Room entity mapped to the `auto_sport` database table.

```kotlin
@Entity(
    tableName = "auto_sport", indices = [Index(value = ["startTime"], unique = true)]
)
@Parcelize
data class OreoAutoSportData(
    @PrimaryKey(autoGenerate = true) var id: Int = 0,
    @ColumnInfo(name = "is_synced")   var isSynced: Boolean = false,
    @ColumnInfo(name = "is_accepted") var isAccepted: Boolean = false,
    @ColumnInfo(name = "duration")    var duration: Int = 0,          // seconds
    @ColumnInfo(name = "intensity")   var intensity: Int? = null,     // 0=Easy,1=Easy,2=Moderate,3+=Hard
    @ColumnInfo(name = "calories")    var calories: Int = 0,
    @ColumnInfo(name = "startTime")   var startTime: Long = 0,        // milliseconds epoch
    @ColumnInfo(name = "steps")       var steps: Int = 0,
    @ColumnInfo(name = "type")        var type: String? = null,       // e.g. "walking", "running"
    @ColumnInfo(name = "hr")          var hrData: String? = null,     // JSON array of Int
    @SerializedName("date")           var date: String? = null        // "yyyy-MM-dd"
) : ColorfitData(), Parcelable
```

### Field Reference

| Field | Type | Source | Description |
|---|---|---|---|
| `id` | `Int` | Auto-generated by Room | Primary key |
| `isSynced` | `Boolean` | Set by app | `true` after dismissed or accepted by user |
| `isAccepted` | `Boolean` | Set by app | Currently always `false` in queries; `true` marks user-accepted |
| `duration` | `Int` | SDK `autoSportDuration` / `autoActiveDuration` | Activity duration in **seconds** |
| `intensity` | `Int?` | SDK `autoSportIntensity` / `autoActiveSportLevel` | 0=Easy, 1=Easy, 2=Moderate, ≥3=Hard |
| `calories` | `Int` | SDK `autoSportKcal` / `autoSctiveKcal` | Calories burned |
| `startTime` | `Long` | SDK Unix seconds `* 1000L` | Start time in **milliseconds** |
| `steps` | `Int` | SDK `autoSportSteps` / `autoActiveSteps` | Step count |
| `type` | `String?` | `getSportName(autoSportType)` | Activity name string e.g. `"walking"`, `"running"` |
| `hrData` | `String?` | `Gson().toJson(it.hrData)` | JSON-serialised `List<Int>` of heart rate samples (may be `"[]"`) |
| `date` | `String?` | Set during server sync, not during parse | `"yyyy-MM-dd"` |

## 3. SDK Beans from ZH SDK (Raw BLE Layer)

### `AutoSportDataBean` — Legacy path (via `AutoSportDataCallBack`)

Used when `ControlBleTools.getInstance().getAutoSportData(null)` fires:

| SDK Field | Maps to `OreoAutoSportData` |
|---|---|
| `autoSportDuration` | `duration` |
| `autoSportIntensity` | `intensity` |
| `autoSportKcal` | `calories` |
| `autoSportStartTime` | `startTime * 1000L` |
| `autoSportSteps` | `steps` |
| `autoSportType` | `type` (via `getSportName()`) |
| `hrData` (List<Int>) | `hrData` (Gson JSON string) |

**Filter:** Only beans where `autoSportKcal > 15` are added.

### `AutoActiveSportBean` — Newer path (via `FitnessDataCallBack.onRingAutoActiveSportData`)

The bean wraps a list `.sportData`, each item has:

| SDK Field | Maps to `OreoAutoSportData` |
|---|---|
| `autoActiveDuration` | `duration` |
| `autoActiveSportLevel` | `intensity` |
| `autoSctiveKcal` | `calories` |
| `autoActiveStartTime` | `startTime * 1000L` |
| `autoActiveSteps` | `steps` |
| `autoActiveSportType` | `type` (via `getSportName()`) |

**No calories filter** — all items in the list are stored.

Both bean types are parsed by the two `DataConverter.parseAutoSport()` overloads.

## 5. Step-by-Step Pipeline

### Step 1: BLE Data Arrives from Device

When the app triggers a sync, it calls multiple SDK commands simultaneously:

```kotlin
// ZhUserActivityHandler.syncUserActivityByMode()
ControlBleTools.getInstance().getDailyHistoryData(mode, null)  // daily fitness + sleep
ControlBleTools.getInstance().getAutoSportData(null)           // auto detected sport data
ControlBleTools.getInstance().getFitnessSportIdsData(null)     // recorded workouts
```

For Luna Band, `mode = 3` (DAILY_HISTORY_MODE_ALL — transmit today + history).

The device transfers its stored auto-sport records over BLE. The ZH SDK parses the BLE packets and fires the registered callbacks.

### Step 3: `DataConverter.parseAutoSport()` — Raw → App Model

**File:** `noisefit_zh_sdk/src/main/java/com/noisefit_zhsdk/handler/DataConverter.kt`

#### Overload 1 — from `AutoActiveSportBean` (newer path, no calorie filter)

```kotlin
fun parseAutoSport(
    data: AutoActiveSportBean,
    colorFitDevice: ColorFitDevice
): List<OreoAutoSportData> {
    val result = ArrayList<OreoAutoSportData>()
    data.sportData.forEach {
        val oreoAutoSportData = OreoAutoSportData()
        oreoAutoSportData.steps     = it.autoActiveSteps
        oreoAutoSportData.startTime = it.autoActiveStartTime * 1000L  // seconds → milliseconds
        oreoAutoSportData.intensity = it.autoActiveSportLevel
        oreoAutoSportData.isAccepted = false
        oreoAutoSportData.duration  = it.autoActiveDuration
        oreoAutoSportData.calories  = it.autoSctiveKcal
        oreoAutoSportData.type      = getSportName(it.autoActiveSportType, colorFitDevice)
        result.add(oreoAutoSportData)
    }
    return result
}
```

#### Overload 2 — from `MutableList<AutoSportDataBean>` (legacy path, calorie filter)

```kotlin
fun parseAutoSport(
    p0: MutableList<AutoSportDataBean>?,
    colorFitDevice: ColorFitDevice
): List<OreoAutoSportData> {
    val data = ArrayList<OreoAutoSportData>()
    p0?.forEach {
        if (it.autoSportKcal > 15) {          // ← only workouts burning > 15 kcal stored
            val oreoAutoSportData = OreoAutoSportData()
            oreoAutoSportData.steps     = it.autoSportSteps
            oreoAutoSportData.startTime = it.autoSportStartTime * 1000L
            oreoAutoSportData.intensity = it.autoSportIntensity
            oreoAutoSportData.isAccepted = false
            oreoAutoSportData.duration  = it.autoSportDuration
            oreoAutoSportData.calories  = it.autoSportKcal
            oreoAutoSportData.type      = getSportName(it.autoSportType, colorFitDevice)
            oreoAutoSportData.hrData    = gson.toJson(it.hrData)  // JSON array of Int
            data.add(oreoAutoSportData)
        }
    }
    return data
}
```

### Step 6: `RingConnectionService` receives and persists to DB

**File:** `app/src/main/java/com/oreo/receiver/service/RingConnectionService.kt`  
**Lines:** ~2046–2091

This foreground service observes `sessionManager.userActivityCallback` and handles `AutoSportDataObtained`:

```kotlin
sessionManager.userActivityCallback.observe(this) { event ->
    event.peekContent()?.let {
        when (it) {

            is UserActivityCallback.AutoSportDataObtained -> {
                // 1. Show local push notification for the newest workout (if recent enough)
                it.data.firstOrNull()?.let { workout ->
                    val timeStamp = DateFormats.lastClearDataTimeStamp(DELETE_DB_DAYS)
                    if (workout.startTime > timeStamp && sessionManager.showLocalNotification()) {
                        NotificationUtil.showWorkoutLocalNotification(
                            this, workout, resourcesProvider
                        )
                    }
                }

                // 2. Persist all workouts to Room DB (dedup by startTime)
                GlobalScope.launch {
                    syncRepository.saveAutoWorkoutData(it.data)
                        .collect { resource ->
                            when (resource) {
                                is CacheResult.Success -> {
                                    // 3. Signal the home screen to show badge/refresh
                                    sessionManager.setShowSyncOfflineData(
                                        Event(HealthOverviewDataType.AUTO_WORKOUT)
                                    )
                                }
                                is CacheResult.GenericError -> { /* error logging */ }
                            }
                        }
                }
            }
            // ... other callbacks handled here ...
        }
    }
}
```

### Step 7: Room DB — `auto_sport` table

#### DAO — `OreoAutoSportDao`

**File:** `app/src/main/java/com/oreo/data/db/database/OreoAutoSportDao.kt`

```kotlin
@Dao
interface OreoAutoSportDao : BaseDao<OreoAutoSportData> {

    // Fetch all pending (not accepted, not synced) workouts newer than retention window
    @Query("SELECT * FROM auto_sport where is_accepted = :isAccepted AND is_synced=:isSynced AND startTime > :startTimeStamp order by startTime DESC")
    fun getAllNotAcceptingData(isAccepted: Boolean, isSynced: Int, startTimeStamp: Long): List<OreoAutoSportData>?

    // Dedup check — find by exact start time before inserting
    @Query("SELECT * FROM auto_sport where startTime = :startTime")
    fun getWorkoutByTime(startTime: Long): OreoAutoSportData?

    // Mark single workout as handled (synced=1)
    @Query("UPDATE auto_sport SET is_synced = :isSynced WHERE id = :id")
    fun markWorkoutSynced(isSynced: Int, id: Int)

    // Mark all workouts as handled
    @Query("UPDATE auto_sport SET is_synced = :isSynced")
    fun markWorkoutSyncedAll(isSynced: Int)

    // Hard delete by id
    @Query("Delete FROM auto_sport where id = :id")
    fun deleteAutoSport(id: Int)

    // Hard delete all un-accepted workouts
    @Query("Delete FROM auto_sport where is_accepted = :isAccepted")
    fun deleteAllAutoSport(isAccepted: Boolean)

    // Prune rows older than retention window
    @Query("DELETE FROM auto_sport WHERE startTime <= :time")
    fun deleteOlderData(time: Long): Int
}
```

**Unique index on `startTime`** means duplicate BLE deliveries are silently ignored by Room's `INSERT OR IGNORE` (provided by `BaseDao`).

```kotlin
override suspend fun saveAutoWorkoutData(data: List<OreoAutoSportData>): Flow<CacheResult<Boolean?>> {
```

#### `getNotAcceptingData()` — grouping logic

```kotlin
fun getNotAcceptingData() {
    viewModelScope.launch(Dispatchers.IO) {
        syncRepository.getAutoWorkoutData().collect { resource ->
            when (resource) {
                is CacheResult.Success -> {
                    val hm = LinkedHashMap<String, ArrayList<OreoAutoSportData>>()
                    resource.value?.forEach {
                        // Group each workout by its date string ("yyyy-MM-dd")
                        val date = DateFormats.convertTimestampToDate(
                            it.startTime, DateFormats.dateFormat3()
                        )
                        if (hm.containsKey(date)) {
                            hm[date]!!.add(it)
                        } else {
                            hm[date] = arrayListOf(it)
                        }
                    }
                    val dateList = ArrayList<String>()
                    hm.forEach { dateList.add(it.key) }
                    dateList.reverse()    // newest date first
                    _oreoAutoSportData.postValue(Pair(dateList, hm))
                }
            }
        }
    }
}
```

## 1. SDK Layer - ZH SDK Integration

### 1.1 ZhUpdateDeviceUnitsHandler.kt
**Location:** `noisefit_zh_sdk/src/main/java/com/noisefit_zhsdk/handler/ZhUpdateDeviceUnitsHandler.kt`

This is the core SDK integration layer that receives ongoing workout callbacks from the device.

```kotlin
package com.noisefit_zhsdk.handler

import com.zhapp.ble.callback.RingSportCallBack
import com.zhapp.ble.bean.RingSportStatusBean
import com.noisefit_commans.interfaces.device_data.UpdateDeviceDataCallback
import com.noisefit_commans.utils.AppLogs
import com.noisefit_commans.utils.LOGS
import com.google.gson.Gson

class ZhUpdateDeviceUnitsHandler {
    
    companion object {
        private const val TAG = "ZhUpdateDeviceUnitsHandler"
    }

    // Initialize callback in attachCallbacks() or init()
    init {
        CallBackUtils.ringSportCallBack = ringSportCallback
    }

    /**
     * Core callback that receives ongoing workout status from Luna Band device.
     * This is triggered by the SDK when:
     * - Workout is started on device
     * - Workout state changes (pause/resume)
     * - Workout ends
     */
    private val ringSportCallback = object : RingSportCallBack {
        override fun onRingSportStatus(bean: RingSportStatusBean?) {
            LOGS.d(TAG, "onRingSportStatus ${Gson().toJson(bean)}")
            LOGS.d("startWorkout onRingSportStatus bean:::: ${Gson().toJson(bean)}")
            
            if (bean == null) return

            // Check if there's an active ongoing workout
            if (bean.startTime > 0L &&
                bean.sportStatus != RingSportCallBack.RingSportStatus.SPORT_STATUS_END.status &&
                (bean.startResult == RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_NONE.result ||
                 bean.startResult == RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_SPORTING.result)
            ) {
                // Publish ongoing workout state to the app
                publishOngoingWorkoutState(
                    duration = bean.duration,
                    sportStatus = bean.sportStatus,
                    sportType = bean.sportType,
                    startTimeStamp = bean.startTime
                )
            }

            // Handle workout start failures
            if (bean.startResult != RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_NONE.result &&
                bean.startResult != RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_SPORTING.result
            ) {
                if (!isLunaBandDevice()) {
                    setAutoWorkoutStatus(true)
                }
                stopLocationTracking()
                
                when (bean.startResult) {
                    RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_LOW_POWER.result -> {
                        AppLogs.sendAppLogs("Workout failed from ring Reason: Low Battery")
                        publishWorkoutActionFailure(
                            PendingWorkoutAction.START,
                            revertWorkoutStartState = true
                        )
                        stopWorkout("Low Battery")
                    }

                    RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_UN_WEAR.result -> {
                        AppLogs.sendAppLogs("Workout failed from ring Reason: Device not worn")
                        publishWorkoutActionFailure(
                            PendingWorkoutAction.START,
                            revertWorkoutStartState = true
                        )
                    }

                    RingSportCallBack.RingSportStartResult.SPORT_START_RESULT_CHARGING.result -> {
                        AppLogs.sendAppLogs("Workout failed from ring Reason: Ring on Charging")
                        publishWorkoutActionFailure(
                            PendingWorkoutAction.START,
                            revertWorkoutStartState = true
                        )
                    }
                }
            }

            // Handle workout stop confirmation
            if (bean.sportStatus == RingSportCallBack.RingSportStatus.SPORT_STATUS_NONE.status &&
                pendingWorkoutAction == PendingWorkoutAction.STOP &&
                !bean.isSporting &&
                bean.startTime == 0L
            ) {
                publishWorkoutStoppedConfirmed()
            }

            // Handle workout end from device
            if (bean.sportStatus == RingSportCallBack.RingSportStatus.SPORT_STATUS_END.status) {
                if (!isLunaBandDevice()) {
                    setAutoWorkoutStatus(true)
                }
                if (bean.endReason == RingSportCallBack.RingSportEndReason.SPORT_END_REASON_NONE.reason) {
                    publishWorkoutStoppedConfirmed()
                } else {
                    stopLocationTracking()
                }

                // Handle device-initiated workout end reasons
                if (bean.endReason != RingSportCallBack.RingSportEndReason.SPORT_END_REASON_NONE.reason) {
                    when (bean.endReason) {
                        RingSportCallBack.RingSportEndReason.SPORT_END_REASON_LOW_POWER.reason -> {
                            AppLogs.sendAppLogs("Workout failed from ring Reason: Low Battery")
                            stopWorkout("Low Battery")
                        }

                        RingSportCallBack.RingSportEndReason.SPORT_END_REASON_TIMEOUT.reason -> {
                            AppLogs.sendAppLogs("Workout failed from ring Reason: Exercise 8 hours timeout")
                        }

                        RingSportCallBack.RingSportEndReason.SPORT_END_REASON_NO_MEMORY.reason -> {
                            AppLogs.sendAppLogs("Workout failed from ring Reason: Insufficient device memory")
                        }
                    }
                }
            }
        }
    }

    /**
     * Publishes ongoing workout state to the app layer.
     * This method is the bridge between SDK and app logic.
     * 
     * @param duration Current workout duration in seconds
     * @param sportStatus Workout status (1=START, 2=PAUSE, 3=RESUME, 4=END)
     * @param sportType Device sport type ID
     * @param startTimeStamp Workout start timestamp in seconds
     */
    private fun publishOngoingWorkoutState(
        duration: Int,
        sportStatus: Int,
        sportType: Int,
        startTimeStamp: Long
    ) {
        secondaryScreenStopConfirmed = false
        
        // Send callback to service layer
        testUpdateDeviceDataCallback?.onUpdateDataReceived(
            UpdateDeviceDataCallback.OngoingWorkoutData(
                duration,
                sportStatus,
                sportType,
                startTimeStamp
            )
        )

        // Handle pending workout actions
        when (pendingWorkoutAction) {
            PendingWorkoutAction.START -> {
                confirmPendingWorkoutStartIfNeeded()
                pendingWorkoutAction = null
                testUpdateDeviceDataCallback?.onUpdateDataReceived(
                    UpdateDeviceDataCallback.WorkoutStartState(true)
                )
            }

            PendingWorkoutAction.PAUSE -> {
                if (sportStatus == RingSportCallBack.RingSportStatus.SPORT_STATUS_PAUSE.status) {
                    pendingWorkoutAction = null
                    testUpdateDeviceDataCallback?.onUpdateDataReceived(
                        UpdateDeviceDataCallback.WorkoutPaused(true)
                    )
                }
            }

            PendingWorkoutAction.RESUME -> {
                if (sportStatus == RingSportCallBack.RingSportStatus.SPORT_STATUS_START.status ||
                    sportStatus == RingSportCallBack.RingSportStatus.SPORT_STATUS_RESUME.status
                ) {
                    pendingWorkoutAction = null
                    testUpdateDeviceDataCallback?.onUpdateDataReceived(
                        UpdateDeviceDataCallback.WorkoutResumed(true)
                    )
                }
            }

            PendingWorkoutAction.STOP,
            null -> Unit
        }
    }

    /**
     * Secondary screen (display devices) sport status handler.
     * Similar to RingSportCallBack but for devices with displays.
     */
    private fun handleSecondaryScreenSportStatus(bean: SportStatusBean?) {
        if (bean == null) return

        if (bean.timestamp <= 0L) {
            when (pendingWorkoutAction) {
                PendingWorkoutAction.START -> publishWorkoutActionFailure(PendingWorkoutAction.START)
                PendingWorkoutAction.PAUSE -> publishWorkoutActionFailure(PendingWorkoutAction.PAUSE)
                PendingWorkoutAction.RESUME -> publishWorkoutActionFailure(PendingWorkoutAction.RESUME)
                PendingWorkoutAction.STOP -> publishWorkoutStoppedConfirmed()
                null -> Unit
            }
            return
        }

        val sportStatus = if (bean.isPaused) {
            SecondaryScreenSportCallBack.SportState.PAUSE.state
        } else {
            SecondaryScreenSportCallBack.SportState.START.state
        }

        publishOngoingWorkoutState(
            duration = bean.duration.toInt(),
            sportStatus = sportStatus,
            sportType = bean.sportType,
            startTimeStamp = bean.timestamp
        )
    }

    /**
     * Sport Status Values from SDK:
     * - SPORT_STATUS_NONE = 0
     * - SPORT_STATUS_START = 1 (workout started or running)
     * - SPORT_STATUS_PAUSE = 2 (workout paused)
     * - SPORT_STATUS_RESUME = 3 (workout resumed from pause)
     * - SPORT_STATUS_END = 4 (workout ended)
     */
}
```

## 3. Session Manager - Business Logic Layer

### 3.1 SessionManager.kt
**Location:** `app/src/main/java/com/noisefit/session/SessionManager.kt`

Central business logic handler that validates and processes ongoing workout detection.

```kotlin
package com.noisefit.session

import androidx.lifecycle.MutableLiveData
import com.noisefit_commans.data.local.abstraction.RingDataStore
import com.noisefit_commans.data.model.DetectedOngoingWorkout
import com.noisefit_commans.data.model.OWorkoutListModal
import com.noisefit_commans.location.LocationUtils
import com.noisefit_commans.utils.AppLogs
import com.noisefit_commans.utils.Event
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.GlobalScope
import kotlinx.coroutines.launch
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class SessionManager
@Inject constructor(
    private val ringDataStore: RingDataStore
) {

    companion object {
        const val TAG = "SessionManager"
    }

    /**
     * LiveData that emits ongoing workout events.
     * Observed by OreoMainActivity to trigger navigation.
     */
    var ongoingWorkoutDetected =
        MutableLiveData<Event<Pair<DetectedOngoingWorkout, OWorkoutListModal>>>()

    /**
     * Timestamp of last ongoing workout detection to prevent duplicates
     */
    var lastOngoingWorkoutTimestamp: Long = 0L

    /**
     * Core function that validates and processes ongoing workout detection.
     * 
     * Flow:
     * 1. Retrieve saved workout from local storage
     * 2. Validate if detected workout matches saved workout
     * 3. If match: Post LiveData event and start location tracking if needed
     * 4. If no match: Clean up and re-enable auto workout detection
     * 
     * @param duration Current workout duration in seconds
     * @param sportStatus Workout status (1=START, 2=PAUSE, 3=RESUME, 4=END)
     * @param sportType Device sport type ID
     * @param startTimeStamp Workout start timestamp in seconds (NOT milliseconds)
     */
    fun onGoingWorkoutDetected(
        duration: Int, 
        sportStatus: Int, 
        sportType: Int, 
        startTimeStamp: Long
    ) {
        GlobalScope.launch(Dispatchers.IO) {
            // Get the saved ongoing workout from local storage
            val savedWorkout = ringDataStore.getOngoingRecordWorkout() ?: return@launch
            
            AppLogs.sendAppLogs(
                "onGoingWorkoutDetected $duration $sportStatus $sportType $startTimeStamp | Saved Workout ->$savedWorkout"
            )
            
            val deviceType = ringDataStore.getRingDevice()?.deviceType
            
            /**
             * Validation Logic:
             * - startTimeStamp must match saved workout start time
             * - sportType must match saved workout type (with device-specific mapping)
             * 
             * This prevents false positives and ensures we're detecting the correct workout.
             */
            if (savedWorkout.first == startTimeStamp &&
                savedWorkout.second.matchesSportType(sportType, deviceType)
            ) {
                // Valid ongoing workout detected - post event
                ongoingWorkoutDetected.postValue(
                    Event(
                        Pair(
                            DetectedOngoingWorkout(
                                startTimeStamp, 
                                duration, 
                                sportStatus
                            ), 
                            savedWorkout.second
                        )
                    )
                )
                
                // Start location tracking if workout requires GPS
                if (savedWorkout.second.isGpsRequired == 1) {
                    LocationUtils.startLocationService()
                }
            } else {
                // Mismatch detected - clean up and reset
                AppLogs.sendAppLogs(
                    "onGoingWorkoutDetected MISMATCH - cleaning up. " +
                    "Expected: ${savedWorkout.first}/${savedWorkout.second.ringId}, " +
                    "Got: $startTimeStamp/$sportType"
                )
                ringDataStore.deleteOngoingRecordWorkout()
                LocationUtils.stopLocationService()
                
                // Re-enable auto workout detection on device
                sendUpdateQueryAction(UpdateDeviceAction.SetAutoWorkoutStatus(true))
            }
        }
    }
}
```

```kotlin
package com.noisefit.oreo

import android.os.Bundle
import androidx.activity.viewModels
import androidx.appcompat.app.AppCompatActivity
import androidx.core.os.bundleOf
import androidx.navigation.NavController
import com.noisefit.luna.R
import com.noisefit_commans.utils.LOGS
import dagger.hilt.android.AndroidEntryPoint

@AndroidEntryPoint
class OreoMainActivity : AppCompatActivity() {

    private val viewModel: OreoMainViewModel by viewModels()
    private var navController: NavController? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_oreo_main)
        
        setupObservers()
    }

    private fun setupObservers() {
        /**
         * CRITICAL OBSERVER: Ongoing Workout Detection
         * 
         * This observer listens for ongoing workout events from SessionManager.
         * When an ongoing workout is detected:
         * 1. Check if already on workout screen (prevent duplicate navigation)
         * 2. Navigate to RecordWorkoutFragmentV2 with workout data
         * 3. Pass both workout config and ongoing workout state
         * 
         * Event wrapper ensures one-time consumption of events.
         */
        viewModel.sessionManager.ongoingWorkoutDetected.observe(this) {
            it.getContent()?.let { pair ->
                LOGS.d("OreoMainActivity", "Ongoing workout detected: ${pair.first}, ${pair.second}")
                
                // Prevent navigation if already on workout screen
                if (navController?.currentDestination?.id != R.id.recordWorkoutFragmentV2) {
                    navController?.navigate(
                        R.id.recordWorkoutFragmentV2, 
                        bundleOf(
                            "workout" to pair.second,           // OWorkoutListModal
                            "onGoingWorkout" to pair.first,     // DetectedOngoingWorkout
                        )
                    )
                }
            }
        }
    }
}
```

### 4.2 RecordWorkoutFragmentV2.kt
**Location:** `app/src/main/java/com/oreo/ui/recordworkout/v2/RecordWorkoutFragmentV2.kt`

Workout screen that handles ongoing workout initialization and display.

```kotlin
package com.oreo.ui.recordworkout.v2

import android.os.Bundle
import android.view.View
import androidx.fragment.app.viewModels
import androidx.navigation.fragment.navArgs
import com.noisefit.luna.databinding.FragmentRecordWorkoutV2Binding
import com.noisefit_commans.ui.BaseFragment
import com.noisefit_commans.utils.LOGS
import dagger.hilt.android.AndroidEntryPoint

@AndroidEntryPoint
class RecordWorkoutFragmentV2 :
    BaseFragment<FragmentRecordWorkoutV2Binding>(FragmentRecordWorkoutV2Binding::inflate) {

    val navArgs: RecordWorkoutFragmentV2Args by navArgs()
    val viewModel: RecordWorkoutV2ViewModel by viewModels()

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)
        
        LOGS.d("RECORD_WORKOUT", "onViewCreated ${viewModel.currentWorkoutState}")

        /**
         * Initialize workout configuration from navigation arguments
         */
        navArgs.workout.let {
            LOGS.d("RECORD_WORKOUT", "workout data - ${viewModel.currentWorkoutState} - $it")
            viewModel.workout = it
            binding.tvWorkoutTitle.text = it.getTranslatedActivityName()
            binding.ivWorkoutImage.loadImage(binding.ivWorkoutImage.context, it.iconUrl)
            viewModel.sportStartTime =
                viewModel.ringDataStore.getOngoingRecordWorkout()?.first ?: 0L
        }

        /**
         * CRITICAL: Handle Ongoing Workout Initialization
         * 
         * If onGoingWorkout argument is present, this is an auto-detected workout.
         * Initialize UI based on current workout state.
         */
        val ongoingWorkoutArgs = navArgs.onGoingWorkout

        if (ongoingWorkoutArgs != null) {
            LOGS.d("RECORD_WORKOUT", "ongoing - $ongoingWorkoutArgs")
            
            // Initialize ViewModel with ongoing workout data
            viewModel.initFromOngoing(
                ongoingWorkoutArgs.duration.toLong(), 
                ongoingWorkoutArgs.sportStatus
            )
            
            /**
             * Sport Status Handling:
             * - sportStatus == 1: START - workout is running
             * - sportStatus == 2: PAUSE - workout is paused
             * - sportStatus == 3: RESUME - workout resumed (treat as running)
             */
            if (ongoingWorkoutArgs.sportStatus == 1 || ongoingWorkoutArgs.sportStatus == 3) {
                // Workout is active - start UI in running state
                startWorkoutUi()
            } else if (ongoingWorkoutArgs.sportStatus == 2) {
                // Workout is paused - show paused state
                ongoingWorkoutState()
                pauseWorkout()
                viewModel.updateTimer()
            }
        } else if (viewModel.ringDataStore.getOngoingRecordWorkout() != null) {
            // There's a saved workout but no ongoing args - navigate back
            LOGS.d("RECORD_WORKOUT", "navigating back - stale workout")
            navigateUpSafe()
        }

        setupUI()
        setupListeners()
    }

    /**
     * Sets up UI for active workout state
     */
    private fun startWorkoutUi() {
        binding.lytStartWorkout.root.gone()
        binding.lytOnGoingWorkout.root.visible()
        binding.lytPausedWorkout.root.gone()
        viewModel.startTimer()
        viewModel.currentWorkoutState = 1
    }

    /**
     * Sets up UI for ongoing (active) workout state
     */
    private fun ongoingWorkoutState() {
        binding.lytStartWorkout.root.gone()
        binding.lytOnGoingWorkout.root.gone()
        binding.lytPausedWorkout.root.visible()
        viewModel.currentWorkoutState = 2
    }

    /**
     * Pauses the workout timer
     */
    private fun pauseWorkout() {
        viewModel.pauseTimer()
    }

    /**
     * Sets up workout control button listeners
     */
    private fun setupListeners() {
        // Resume button - sends RESUME command to device
        binding.btnResume.setOnClickListener {
            val sportId = getRequestedSportId()
            if (sportId == null) {
                showWorkoutCommandError()
                return@setOnClickListener
            }

            binding.progressBar.root.visible()
            viewModel.sessionManager.sendUpdateQueryAction(
                UpdateDeviceAction.UpdateOngoingWorkout(
                    sportId,
                    viewModel.sportStartTime,
                    3  // RESUME status
                )
            )
        }

        // Pause button - sends PAUSE command to device
        binding.btnPause.setOnClickListener {
            binding.progressBar.root.visible()

            val sportId = getRequestedSportId()
            if (sportId == null) {
                showWorkoutCommandError()
                return@setOnClickListener
            }

            viewModel.sessionManager.sendUpdateQueryAction(
                UpdateDeviceAction.UpdateOngoingWorkout(
                    sportId,
                    viewModel.sportStartTime,
                    2  // PAUSE status
                )
            )
        }

        // End button - stops workout
        binding.btnEnd.setOnClickListener {
            if (!viewModel.isDeviceConnected()) {
                return@setOnClickListener
            }
            onCrossClicked()
        }
    }

    /**
     * Get the device-specific sport ID for the current workout
     */
    private fun getRequestedSportId(): Int? {
        val deviceType = viewModel.ringDataStore.getRingDevice()?.deviceType
        return viewModel.workout?.getRequestedSportId(deviceType)
    }
}
```

## 6. Complete Data Flow

### Detailed Step-by-Step Flow

1. **Device Event**
   - User starts workout on Luna Band device
   - Device stores workout start time and sport type
   - Device begins broadcasting workout status via BLE

2. **SDK Reception (ZhUpdateDeviceUnitsHandler)**
   - `RingSportCallBack.onRingSportStatus()` receives device status
   - Validates: `startTime > 0`, `sportStatus != END`, `startResult == SPORTING`
   - Calls `publishOngoingWorkoutState()` with workout details

3. **Service Layer (RingConnectionService)**
   - Receives `UpdateDeviceDataCallback.OngoingWorkoutData`
   - Forwards to `SessionManager.onGoingWorkoutDetected()`

4. **Business Logic (SessionManager)**
   - Retrieves saved workout from `RingDataStore`
   - Validates match:
     * Start timestamp must match
     * Sport type must match (with device mapping)
   - If valid:
     * Posts to `ongoingWorkoutDetected` LiveData
     * Starts location service if GPS required
   - If invalid:
     * Cleans up saved workout
     * Re-enables auto workout detection

5. **UI Layer (OreoMainActivity)**
   - Observes `ongoingWorkoutDetected` LiveData
   - Checks if already on workout screen
   - Navigates to `RecordWorkoutFragmentV2` with:
     * `workout`: OWorkoutListModal
     * `onGoingWorkout`: DetectedOngoingWorkout

6. **Workout Screen (RecordWorkoutFragmentV2)**
   - Receives navigation arguments
   - Initializes ViewModel with duration and status
   - Sets UI state based on `sportStatus`:
     * 1 or 3: Start workout UI (running)
     * 2: Show paused UI
   - User can pause/resume/stop workout
   - Commands sent back to device via `UpdateDeviceAction`

## 9. Common Issues & Troubleshooting

### Issue 1: Workout Not Detected
**Symptoms:** App doesn't navigate to workout screen when device has ongoing workout

**Possible Causes:**
1. Sport type mismatch between device and app
2. Start timestamp not saved in RingDataStore
3. Observer not registered in OreoMainActivity
4. SDK callback not properly attached

**Debug Steps:**
```kotlin
// Add logs in SessionManager.onGoingWorkoutDetected()
AppLogs.sendAppLogs("Saved: ${savedWorkout.first}/${savedWorkout.second.ringId}")
AppLogs.sendAppLogs("Received: $startTimeStamp/$sportType")
AppLogs.sendAppLogs("Match result: ${savedWorkout.first == startTimeStamp}")
```

### Issue 2: Duplicate Navigation
**Symptoms:** Navigation triggered multiple times

**Fix:** Check navigation guard in OreoMainActivity:
```kotlin
if (navController?.currentDestination?.id != R.id.recordWorkoutFragmentV2) {
    // Navigate
}
```

### Issue 3: Wrong Sport Type Display
**Symptoms:** Workout screen shows wrong workout name/icon

**Cause:** Sport type mapping incorrect for Luna Band

**Fix:** Verify `getRequestedSportId()` mapping in OWorkoutListModal

### Issue 4: Duration Not Updating
**Symptoms:** Duration stays at initial value

**Fix:** Ensure ViewModel timer started in RecordWorkoutFragmentV2:
```kotlin
if (ongoingWorkoutArgs.sportStatus == 1 || ongoingWorkoutArgs.sportStatus == 3) {
    startWorkoutUi()  // This starts the timer
}
```

### Issue 5: Location Not Starting
**Symptoms:** GPS workouts don't track location

**Fix:** Verify in SessionManager:
```kotlin
if (savedWorkout.second.isGpsRequired == 1) {
    LocationUtils.startLocationService()
}
```
